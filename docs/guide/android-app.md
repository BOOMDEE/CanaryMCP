# Android App

Android 端是用户控制的采集器，不会在后台自动扫描或定时上传。每类有独立开关；默认关闭。开启类别后，只有点按“同步已授权数据”才会读取并上传一份最新快照。

| 类别 | 内容 | 额外权限与边界 |
| --- | --- | --- |
| 电量状态 | 百分比、充电状态与采集时间 | 无运行时权限。 |
| 位置 | 最近已知坐标、精度、来源时间；大致模式按经纬度网格化 | Android 位置权限和独立类别开关。精确位置是单独选择；关闭精确位置或撤销精确权限时会请求删除旧快照；之后仅在手动同步时上传大致位置。不申请后台位置、不记录轨迹。 |
| 应用使用情况 | 最近 24 小时最多 15 个活跃应用的包名、前台毫秒数、最近使用时间 | 用户必须在 Android“使用情况访问”设置中授权；包名可能透露个人习惯。 |
| 无障碍树快照 | 一次窗口切换后最多 100 个节点的类型、边界、有限文本/描述、应用包名 | 默认关闭；需系统启用服务、App 开关、每次手动“采集下一屏”。两分钟超时自动解除武装；跳过密码节点文本，不执行手势。其他屏幕内容仍可能敏感，且分发政策可能不允许该用途。 |
| 设备摘要 | 厂商/型号、Android 版本、SDK、App 版本、语言、时区 | 不读取 IMEI、Android ID、广告 ID 或序列号。 |
| 网络状态 | 当前 transport（Wi‑Fi/蜂窝/以太网/无/其他）、Internet/validated 与计费状态 | 仅调用 `ConnectivityManager` 读取当下状态；不读取 SSID、IP、MAC、路由或浏览记录。Android 官方说明 `ConnectivityManager` / `NetworkCapabilities` 可用于读取当前网络快照：[网络状态指南](https://developer.android.com/develop/connectivity/network-ops/reading-network-state)。 |
| 存储空间 | 内部存储总量、可用量，向下按 64 MiB 取整，并标记是否低于 1 GiB | 不读取目录、文件名或文件内容。 |

## 权限撤销与删除

在 App 关闭类别会请求删除 Worker 上对应类别的快照。关闭精确位置会先请求删除旧精确快照，大致坐标需你再次手动同步才会上传。撤销位置、使用情况或无障碍系统权限后，App 返回前台时会关闭对应类别并请求删除旧快照；网络失败时服务端删除不能保证即时完成。按“删除所有快照”可请求删除全部云端上下文并清除本地待同步无障碍快照。撤销设备会删除该设备的上下文、令牌、Webhook 配置、投递历史与限流记录，并清除本地 Keystore 凭证。

设备每类只保留最新一份，不保存快照历史；API/MCP 在七天期限后不再返回快照，Worker 每日物理清理过期行。

## 配对令牌

配对生成两个随机 bearer token：设备写入令牌用于 Android 上传/删除，MCP 只读令牌只读该设备数据。Android Keystore 使用 AES-GCM 加密本地令牌和本地 Webhook 配置；D1 只保留读/写令牌哈希，Webhook 目标与签名 key 由单独 Worker secret 做设备绑定 AES-GCM 加密。MCP 只读令牌等同访问凭证，只给可信客户端。

## 无障碍能力的重要风险

无障碍树可能读到屏幕上的验证码、私人通信、医疗/金融信息和其他敏感文字。即便节点文字有上限、密码字段被过滤、只采一屏，也无法保证其他应用不会把敏感内容放在普通节点里。不要在这些屏幕上触发快照。Android 将无障碍服务定位为辅助功能用途；公开分发前要确认目标平台规则和产品用途，维护者可以在发布构建前移除此能力。

## Android 工程命令

在 Android Studio 打开 `Android/`；需 JDK 17、SDK 35，最低 API 26。

```bash
cd Android
./gradlew assembleDebug
./gradlew assembleRelease
```

Debug 构建允许模拟器本机地址 `http://10.0.2.2:8787`；Release 只接受 HTTPS。当前仓库没有已配置的生产签名 key；`assembleRelease` 不等于可分发签名包。
